# 言いたい英語ドリル（SpreadDiary）

**言いたいことが、リングの単語カードになる。** 毎日 3 枚めくって覚え、赤シートをずらして思い出す英語のフレーズ帳。職場・旅行・日常・気持ち・お店・人づきあいの 307 枚を手で用意してあり、入力しなくても今日から使える。自分の言いたい日本語も、Apple Intelligence（端末の中）か Apple の翻訳（端末の中）で英語のカードにできる。

enludus-daily の 2026-11-03 のアプリ（記録: https://github.com/enludus-daily/daily-ideas/issues/3 ）。2026-11-05 に本人の評価（「めっちゃ淡白」「内容がうすすぎる」）を受けて、`.claude/skills/app-quality-bar` の基準で作り直した。リポジトリ名とスキーム名（SpreadDiary）は最初の版のまま。

## トーン（look.md §0：StudyReel のオシャレ・透明感・清潔）

2026-11-05 に本人の評価（「マインスイーパー側に寄せてる。StudyReel 側に寄せて欲しかった。オシャレな感じ」）を受けて、世界観と中身はそのまま、トーンだけを寄せ直した。`python3 scripts/tone-check.py` は exit 0（強い色 0 件）。

- 色：アプリの色は 1 系統。StudyReel の 8 色（水色 `#9EC3E2`・さくら・ピーチ・ミント・ラベンダー・バター・ミルクティー・抹茶、明度 0.74〜0.85）から設定で選ぶ。既定は水色。各色 5 段階（accent / soft / deep / paper / tape）。deep（彩度 0.42 以下）は白文字のボタンと小さな文字だけ
- 場面（職場・旅行・日常・気持ち・お店・人づきあい）は色ではなく、アイコンと小さな札の文字で分ける
- 地はほぼ白 `#F3F6F9`、文字 `#2E3A46`、補助 `#8E9AA6`、罫とカードの線 `#E3E9EF`（0.6〜0.8pt）、余白の線は淡いピンク
- 差し色はピーチ（間違いの ×・「済」のスタンプ）だけ
- 覚えた度合い・練習した量は、テーマ色 1 系統の濃さ 5 段階（罫 → soft → accent 半分 → accent → deep）
- 書体：見出し・英語・大きな数字はセリフ（semibold / medium / regular）、大きな数字は `kerning(-3)`、小さなラベルは `kerning(0.6)`。bold は使わない
- 角丸：カード 6・札 10・ボタン 14・区切り 18（continuous）。余白 4/8/12/16/24/32
- 影：0.06（置いた紙）と 0.08（浮かせた紙）だけ。飾り（テープ・傾け）は今日の 3 枚の扇（±3°）と共有カードだけ

## 世界観（look.md §1）

**このアプリでは〔リング綴じの単語カード〕が〔フレーズ 1 枚〕になり、〔暗記用のシート〕が〔答えを隠して思い出す操作〕になる。**

| 部品 | どこで | 作り |
|---|---|---|
| リング綴じのカード（主役） | 今日の 3 枚・ドリル・束・共有カード | `RingCard.swift`：白い紙に 0.8pt の線、左上の穴に金属のリング（カードの裏に回る所は隠す） |
| 暗記用のシート | ドリルの「めくって思い出す」 | `Marks.swift` の `RedSheet`：淡いテーマ色のすりガラス（ultraThinMaterial＋accent 45%＋0.8pt の縁）。重なった所の答えはぼかして隠す。下へずらすと見える |
| 罫線のノート | 全画面の背景 | `Paper.swift`：0.6pt の罫と、淡いピンクの余白の線 |
| 淡いマーカー・小さなスタンプ | 答え・「済」・連続日数 | 答えの下に淡い緑の帯、細い二重丸のセリフ文字のスタンプ |

## 手応えの表（feel.md §2：静かな動き）

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す（ボタン・札） | 0.98 倍・少し薄く（easeOut 0.15） | 札を選ぶ・シートを開く：`.selection` | なし |
| カードをめくる | Y 軸で 260ms・easeInOut、半分で面を入れ替え、1.05 倍までだけ浮かせる | `.selection` | めくると英語を読み上げる |
| シートをずらす | 指に追従。半分を超えたら easeOut 0.3 で抜け、手前なら戻る | `.selection` | 開いた瞬間に英語を読み上げる |
| 1 つ正解 | テーマ色の細い丸を引く（easeOut 0.3）。答えの線がマーカーの色に。下に答えの帯がフェードで出る | `.selection`（答えを選んだとき） | 正しい英語を読み上げる |
| 連続正解 | 連続の数字が `numericText` で変わり、帯の見出しが「3 連続！」に | なし（連打で鳴らさない） | 読み上げ |
| 間違い | ピーチの細い × を引く。答えの線がピーチに。揺らさない | `.selection`（答えを選んだとき） | 正しい英語を読み上げる |
| 今日の分が終わった | 「済」のスタンプが opacity と 0.96→1 倍で置かれる（easeOut 0.35）。紙吹雪は使わない | `.success` | なし |
| 場面の切れ目 | 画面の切り替えはフェード（easeOut 0.25） | — | — |

効果音を入れない理由：電車や職場で使う学習アプリで、英語の読み上げが音の役目を持つため。
動きを減らす設定がオンなら、めくり・フェード・見本の動きを止め、値を直接変える。振動は設定で切れる。

## 中身（depth.md）

- **フレーズの束 307 枚**（`data/bank/*.txt` → `scripts/build-bank.py` → `App/Resources/PhraseBank.json`）：日本語・英語・丁寧・くだけた・単語（英文の中にそのまま出る）。テストで件数と形を確かめる
- **毎日開く理由**：今日の 3 枚（日付で決まる）／復習（間隔をあけて 1・2・4・7・15・30 日）／今日の目標 5 問の線／連続日数の判子と、途切れても責めない言い方（「おかえりなさい。これまでに合計 n 日」）／18 週のヒートマップ／カード箱／言えるようになった英語の共有カード（`ImageRenderer` で 1080×1920）／毎日のおしらせ（端末の中の通知）
- **問題の型 4 つ**：並べ替え → 穴埋め → めくって赤シートで思い出す → 聞き取り（覚えた度合いで変わる）
- **最初の 10 秒**：3 ページのオンボーディング（めくれるカード・ずれる赤シート・進むカード箱の動く見本）→ 今日の 3 枚
- **状態**：束を読めない・束をすべて通した・復習なし・カードなし・Apple Intelligence が使えない（理由別）・翻訳できない・通知が許可されていない（設定アプリを開く）・カードが見つからない・共有の画像を作れない
- **設定**：1 日の枚数、場面、振動、読み上げの速さ、おしらせと時刻、使い方をもう一度、プライバシーの説明

作らなかったもの：ウィジェット（App ID の追加と App Group が要るため、今回は見送り）、英語以外の言語、同期・共有のアカウント、課金。
